# Bonus 02 — Bilingual Profile

Open `index.html` in a browser. Use the language button to switch between English and Arabic. JavaScript updates the translated text and the document language and direction (`lang` and `dir`). The responsive layout uses CSS logical spacing so it works in both LTR and RTL directions.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — language switching and translations
- `assets/` — profile images used in the preview
